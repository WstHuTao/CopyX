# CopyX 第一版需求

作者：Ivan Jia。

目标平台：macOS 14+ Apple Silicon；Windows 10/11 x64。

普通复制不触发。JavaScript 处理各自配置快捷键，AI 提示词命令共用一个快捷键。按快捷键获取选中纯文本后打开左右对照窗口。左侧只读、右侧可编辑，字符差异包含空白字符，两侧分别复制，用户自行粘贴。复制后保持窗口打开。

方案类型为本地 JavaScript 和 AI 提示词命令，两者独立。脚本输入原文、返回字符串，隔离执行并限制资源。AI 配置由用户填写 API 地址、密钥与模型，支持多组 OpenAI 兼容 Chat Completions 服务配置。提示词可在工作台输入或从历史选择，成功执行后自动记录。允许取消和手动重试，不自动重试。

本地保存方案、模型元信息和加密密钥；不持久保存客户正文。重跑始终以原文为输入，覆盖人工结果前提醒。无富文本、图片、自动粘贴、云同步和步骤串联。

界面将“处理方案”统一命名为“自定义处理”，快捷键只展示当前安装系统的一项。录入时检测已启用处理之间的重复以及全局键位注册冲突，保存时再次核验；冲突不破坏原有绑定。“启用全局快捷键”放在键位输入框旁，只控制后台快捷键触发，关闭后保留工作台手动执行。所有下拉控件使用统一箭头样式。作者 Ivan Jia 位于侧栏“本地运行”下方，以小号浅色文字显示。

API Key 必须加密保存到本地文件，退出后保留、重启自动读取；不调用系统钥匙串、系统凭据或指纹认证。主密钥单独保存为随机本地文件，不使用写死在程序中的共享密钥。旧版系统密文保留并提示重新填写一次，不静默丢弃。

仅在“自定义处理”的 JavaScript 类型下提供“使用模型生成脚本”，作为处理脚本编辑器的编写辅助；处理工作台和 AI 提示词命令类型不提供该入口。用户调用已保存的模型配置，根据自然语言处理要求生成脚本。生成结果检查语法与同步单参数 transform 入口，并自动运行用户测试集后展示预览，由用户明确应用到草稿并继续编辑。保存后仍停留在自定义处理页，不自动执行或跳转；日常快捷键与手动执行仅运行测试通过后生效的本地 JS，不再调用生成模型。支持取消和失败提示，不直接覆盖生效脚本，不自动上传工作台原文或现有脚本。需要核对真实输出时用户自行到工作台运行。

## AI 共享快捷键与提示词历史

所有 AI 提示词命令共用一个全局快捷键。按下后使用最近一次成功执行的提示词与对应模型，处理当前选中的纯文本并显示对照。首次使用时先在工作台手动成功执行一次。没有成功记录，或记录对应的处理和模型关联已变更时，快捷键获取原文并提示在工作台执行。

用过的提示词成功后自动写入本机历史，重启后保留。历史支持使用、收藏、取消收藏、编辑及删除。收藏置顶，两组内部均按最近使用排序。收藏和选用只影响列表和工作台输入，编辑后的文本成功执行一次才接替快捷键默认。删除最近一条后使用下一条成功记录。失败或取消时保留上一次成功记录。

升级保留已有 AI 处理、模型与初始提示词，每个平台沿用首个已启用并填写的旧 AI 键位。只保存提示词及使用关联，客户原文和输出保留在工作台内存中。

## JavaScript 测试集与生效版本

每个自定义处理维护独立测试集，包含名称、输入和预期输出，重启后保留。比较完整字符串，空格、制表符、换行及空字符串不能忽略。所有新增或修改的 JS，包括模型生成和手工修改，都必须至少 1 例且全部通过后才能生效。生成后自动本地测试，失败显示预期、实际结果及差异；失败不自动反复调用模型。

草稿可以随时保存，运行时只用生效版本。测试失败、超时或取消不替换原生效脚本；没有生效版本的新处理不可在工作台或快捷键中运行。修改代码或用例后必须重新测试；后台按具体代码与测试集核验通过记录，界面按钮不能绕过。旧脚本原样升级继续使用并标注尚未验证，修改后的草稿受新规则约束。保存与生效后仍停留在自定义处理页。

测试数据由用户维护并保存在本机；讨论方案时按当前功能要求发送到所选模型，普通工作台正文不自动采集或上传。用户主动维护的测试样例与明确保存的对话，是普通客户正文不落盘约定的明确例外。

## 方案确认与多轮对话

模型辅助改为“讨论方案 → 用户确认 → 生成脚本”。每轮结合当前已有 JS、测试输入、预期、实际结果及用户补充；先说明处理方案，不直接替换脚本。用户可以连续补充，只有明确确认最新方案才能生成。修改代码、测试集或模型后旧方案不能直接使用。生成后仍执行原有测试门禁，失败结果和代码可以带回讨论，不自动调用模型重试。

用户选择对话保存在本机，重启后恢复当前处理的对话、方案、上下文和生成预览；未发送的输入不自动保存。当前草稿不一致时可显式恢复会话草稿，生效版本保持不变。历史测试报告不能代替重启后的本地通过记录。按新要求，当前脚本与完整测试上下文会发送给所选模型，界面说明发送范围，替代旧的可选样例勾选；工作台正文仍不自动参与。


## 模型对话抽屉与 Markdown

模型对话从窗口右侧抽拉打开，窄窗口内保持可用。打开时限制焦点在抽屉内，关闭后回到入口；支持关闭按钮、Esc 和遮罩关闭。收起不会结束正在进行的请求、丢弃当前输入或重置会话，重开后可继续查看和取消；应用生成脚本后收起并回到原编辑区。

用户消息和模型回复支持 Markdown 标题、加粗、列表、表格、引用、删除线、任务列表、行内代码及围栏代码块。长代码和宽表格独立横向滚动，不撑宽抽屉。模型内容不作为原始 HTML 执行，不自动加载远程图片；本地对话继续保存原始文本，不修改讨论、方案确认、生成和测试门禁。


## 自定义处理分享与导入

自定义处理可以按条分享为 `.copyx.json` 文件，包含名称、类型和当前脚本或初始提示词。JavaScript 可主动选择附带测试输入和预期输出。分享文件可在受支持的 Mac 和 Windows 之间传递。模型设置、凭据、快捷键、历史记录和生效状态属于本机数据。

导入增加一条独立草稿，同名自动加后缀。用户检查后保存。JavaScript 沿用接收端的测试与生效流程，AI 草稿可以先保存，使用前绑定本机模型。文件无效或取消时保留原配置。
