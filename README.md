# CopyX

作者为 Ivan。在 macOS 顶部菜单栏选择「CopyX → 关于 CopyX」可查看作者和当前应用版本。

通过专用快捷键获取选中文字，执行本地 JavaScript 或 AI 提示词命令，左右对照、人工编辑，再分别复制原文或结果。

目标平台：macOS 14+ M 系列芯片；Windows 10/11 x64。

## 使用

1. 安装并打开软件。在「自定义处理」编辑或新增处理。
2. 选择 JavaScript 脚本或 AI 提示词命令，录入当前系统的快捷键。JavaScript 处理各自配置键位，所有 AI 提示词命令共用一个键位。输入框按删除键可清空，录入时检查重复和系统注册冲突，保存时再次核验后生效。
3. 本地脚本定义 `function transform(text) { return text; }`，必须返回字符串。默认方案原样返回，避免替用户修改内容。可在工作台载入样例或手动输入原文试运行。
4. 使用 AI 时先到「模型设置」填写 API 地址、API Key、模型名称，保存并测试连接，再将 AI 方案关联到模型。输入地址需包含服务商要求的版本路径，例如 `https://服务地址/v1`，也可填写完整 Chat Completions 请求地址。
5. 在其他应用中选中文字，按对应快捷键，松开组合键，等待对照窗口打开。Mac 首次使用需在系统设置的「隐私与安全性 → 辅助功能」添加并开启 CopyX，再回到工作台点击「权限检查」。
6. 检查差异，必要时编辑右侧，点击「复制原文」或「复制结果」，自行到目标应用粘贴。窗口保持打开。

AI 方案会把原文与提示词发送给你配置的服务。返回内容需人工确认。首次在工作台选择 AI 处理，输入提示词并执行。成功后提示词自动保存在本机，之后按 AI 共享快捷键就会使用最近一次成功的提示词及对应模型。

工作台的「本次提示词」下方最多显示四条快捷提示词，按收藏优先、最近使用排序。点击胶囊填入本次提示词，可继续编辑。打开「提示词历史」可使用、收藏、取消收藏、编辑或删除提示词。收藏优先显示，每组按最近使用排序。选择或编辑后成功执行一次，才会更新快捷键默认命令。删除最近一条后，快捷键使用下一条成功记录。

快捷键输入框旁的“启用全局快捷键”控制是否允许在其他应用中用快捷键启动此处理，关闭后仍可在工作台手动执行。修改需保存后生效。

关闭窗口会隐藏到菜单栏/托盘；从菜单栏/托盘打开或选择退出。普通复制粘贴不触发窗口。

## 自定义处理、测试集与多轮脚本生成

在“自定义处理”选择 JavaScript 类型，维护用例名称、输入和预期输出。完整字符串必须一致，空格、制表符、换行和空字符串均参与比较。用户主动保存的样例和对话保存在本机，建议使用可留存的测试数据。

使用模型生成脚本前，请在当前处理的测试集中添加至少 1 条用例，填写测试输入与预期输出。测试集为空时，点击「使用模型生成脚本」会先切到测试集。有用例后，点击该按钮打开右侧对话抽屉，选择模型、填写处理要求并点击「讨论处理方案」。应用先本地测试当前脚本，将已有代码、测试输入/预期/实际结果与当前对话一并交给模型。模型先解释处理方案；继续填写要求并点击「发送补充意见」可以多轮修改。确认最新方案后，再点击「确认方案并生成脚本」。新脚本自动执行测试并展示差异。失败代码和结果可带回下一轮讨论，不自动重试模型；每次模型请求最多等待 5 分钟，可取消。

对话按自定义处理保存在本机，重启可继续；恢复的历史测试报告仅供参考，应用后需重新运行测试。当前脚本或测试集与方案不一致时不能直接生成，可以更新方案，或选择“恢复会话草稿”；恢复只改变编辑草稿。更换模型会开始新对话，旧历史不会直接转给另一个服务。普通工作台正文不自动采集，日常处理仍只运行已生效的本地 JS，不调用模型。

模型回复支持 Markdown 标题、列表、表格、引用、行内代码和代码块。对话仍按原始文本保存在本机。抽屉可通过关闭按钮、Esc 或点击遮罩收起；关闭不会取消请求，重新打开可查看进度或取消，本次未发送的输入也保留。

点击“应用到脚本编辑器”只更新草稿，并收起抽屉回到编辑区。可继续编辑或“保存草稿”，不会覆盖正在使用的版本。至少 1 例且全部通过后才能“启用此版本”；改变代码或用例后请重新测试。失败或整套超时时仍保留代码供修正，用户取消则丢弃本次未完成结果。保存和生效都留在自定义处理页。

旧版已有脚本升级后继续可用，并标注尚未验证；修改后需通过测试才能替换。测试通过只保证已覆盖样例符合预期，仍需维护边界用例。测试集最多 50 例，单输入/预期最多 64 KB，总样例最多 512 KB；每例 2 秒、整套 15 秒。脚本不能访问文件、网络或系统。

每个处理保存最近一次对话，最多 12 轮讨论；点击“重新开始对话”并确认后，首轮成功时替换原历史。未发送的输入框内容不在历史中。对话保存失败会明确提示，原文件保留，当前结果仍在内存；切勿将此提示当作已保存。

## 分享和导入自定义处理

在「自定义处理」选中一条，点击「分享」，将当前脚本或初始提示词保存为 `.copyx.json` 文件。JavaScript 处理可选择是否附带测试用例。将文件交给对方，对方在「自定义处理」点击「导入处理」，选中文件后即可查看和编辑导入的草稿。同名处理会加上导入后缀。

在底部操作栏点击「保存草稿」或「保存自定义处理」保留导入内容。JavaScript 处理须在接收端通过测试并生效。AI 处理可先保存草稿，执行前选择接收端自己的模型配置。分享文件只包含处理名称、脚本或提示词以及主动选择的测试用例。模型设置、快捷键、历史记录和生效凭据留在原设备。

## API Key 保存方式

API Key 加密后写入本地 config.json，随机主密钥保存为同目录下独立的 master.key。两个文件位于应用数据目录，退出后继续保留；正常重启无需重新填写。密钥不会回显到界面，也不会写入日志。

备份或迁移需同时保护这两个文件。该方案防止配置文件直接暴露明文，但同时获得密文和主密钥的人仍可解密。

旧版由系统加密的 API Key 会提示重新填写一次，其他设置保留。保存和使用 API Key 不再请求钥匙串或指纹授权；复制选文所需的 macOS 辅助功能权限仍按原流程授予。

## 辅助功能已开启但快捷键取文无效

在 CopyX 工作台点击「权限检查」，由实际执行快捷键取文的程序重新检查当前授权。若系统开关已开启，但程序仍提示未授权：

1. 在系统设置 → 隐私与安全性 → 辅助功能中，仅移除旧的 CopyX 条目。
2. 使用「＋」重新添加当前安装的 `/Applications/CopyX.app`，并开启权限。
3. 回到 CopyX 再点「权限检查」。若 macOS 明确要求退出并重新打开，按系统提示操作。显示「辅助功能权限已就绪」后，选中文字并按已保存的快捷键。

当前未公证的 macOS 构建使用临时签名，更新后旧授权记录可能无法匹配当前版本。重新添加授权需由用户本人操作，无需删除配置或 API Key，也不要清除其他应用的权限。长期稳定分发应使用一致的正式签名身份。

## Tauri 安装包与构建

Tauri 版使用系统 WebView，界面及自定义处理流程沿用现有 CopyX。首次运行前退出 Electron 版，Tauri 会复制旧配置、加密密钥和脚本会话到自己的数据目录。Mac 的快捷键取文需要为新应用单独开启辅助功能。预览可从单独目录打开，把新版 `CopyX.app` 放入原安装位置会替换同名应用。Windows 缺少 WebView2 时安装器会尝试联网补装。

需要 Node.js 22.12+ 和 Rust stable。Mac 使用 Apple Silicon 与 Xcode 命令行工具；Windows 使用 x64 MSVC 构建工具及 Windows SDK。安装前端依赖后，在相应系统运行构建命令。

```sh
npm ci
npm run package:tauri:mac
npm run package:tauri:win
```

安装包位于 `src-tauri/target/<目标平台>/release/bundle/`。验证用的 `smoke-test` 编译开关只用于本地回归，发行包使用默认构建命令。

## Electron 对照版开发

需要 Node.js 22.12+。Mac 打包另需 Xcode 命令行工具；Windows 安装包可在 Windows 环境构建。

前端依赖由 Vite 在构建阶段打包。打包后的应用使用界面构建产物和主进程运行依赖。

```sh
npm install
npx install-electron
npm run native:mac
npm start
```

Windows 开发跳过 `native:mac`。`npm run dev` 仅为界面预览，不具备桌面操作能力。

```sh
npm test
npm run test:desktop
npm run test:script-tests
npm run test:drawer
npm run test:prompt-history
npm run test:scheme-share
npm run package:mac
npm run package:win
```

桌面自动化脚本当前针对 Mac，通过真实 Electron 窗口、系统剪贴板和本地 HTTP 服务验证；临时配置与测试密钥运行后删除，不使用真实外部模型账号。API Key 使用本地文件加密保存，重启后自动读取，不调用系统钥匙串或指纹认证；自动化会预置“重新执行”的确认选择，原生确认窗口另作人工检查。设置 TEXT_WORKBENCH_LOCAL_ONLY=1 可只验证本地脚本及编辑复制，不运行模型与凭据测试。

## 界面操作

- 工作台空白区域可直接输入文本或载入样例；处理完成后突出「复制结果」，左右两侧都保留复制按钮。
- 自定义处理默认优先展示脚本和测试集；「编辑设置」展开名称、类型和快捷键，新建、导入时自动展开。
- 脚本与测试集使用页签切换，底部固定提供「保存草稿」「运行全部测试」「启用此版本」。保存草稿同时保存全部待保存配置，不替换正在使用的脚本；启用仍需当前脚本与测试集全部通过。
- AI 辅助抽屉展示讨论、确认、验证三个阶段，可展开查看发送上下文；输入区固定在底部，方案确认入口紧邻方案。
- 模型连接结果显示在底部操作栏，修改配置后需重新测试；密钥配置状态独立显示，继续使用本机加密文件。

## 暂停自定义指令

在「自定义处理」选择指令，使用名称旁的「已启用／已禁用」开关，立即保存并生效，无需再点击底部保存。开关不会提交其他未保存的编辑；新建指令先保存一次后才能切换。禁用会暂停这条指令的快捷键和工作台执行，列表显示「已禁用」；脚本、提示词、测试集、已验证版本与对话仍保留，并可继续维护。

该开关与「启用全局快捷键」相互独立：后者关闭时仍可手动执行；整条指令禁用后两种入口均停止。重新启用会恢复原快捷键配置，并重新检测冲突。所有 AI 指令都禁用时，共享 AI 快捷键也会释放。旧配置默认保持指令启用；分享文件不携带本机的禁用状态。
